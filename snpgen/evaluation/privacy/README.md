# Privacy Evaluation Module

Privacy metrics for evaluating whether synthetic SNP data generated by the VAE + Latent Diffusion Model preserves patient privacy from the training set.

## Overview

This module answers the critical question: **do synthetic genotypes memorize or leak information about individual patients in the training data?**

It evaluates privacy by comparing synthetic (or reconstructed) samples against real training data using distance-based metrics. A holdout test set serves as a calibration baseline — real unseen samples from the same population.

## Metrics

| Metric | What it measures | Ideal value | Interpretation |
|--------|-----------------|-------------|----------------|
| **IMR** (Identical Match Rate) | Exact copies of training samples in synthetic data | 0% | >0% means direct memorization |
| **DCR** (Distance to Closest Record) | Min distance from each synthetic sample to nearest training sample | ≈ holdout DCR | If syn DCR << holdout DCR → memorization |
| **NNAA** (Nearest Neighbor Adversarial Accuracy) | Whether synthetic samples are preferentially close to training data | ~0.5 | <<0.5 → synthetic too close to training |
| **MI** (Membership Inference) | Can we distinguish train vs holdout by distance to synthetic? | AUC ~0.5 | AUC >>0.5 → model leaks training membership |
| **NNDR** (Nearest Neighbor Distance Ratio) | Ratio of 1st/2nd nearest neighbor distance (copying detection) | ~1.0 | <<1.0 → synthetic copies specific real samples |
| **MAF** (Allele Frequency Drift) | Per-SNP allele frequency correlation between real and synthetic | r > 0.99 | Fidelity check; complements privacy metrics |

## Module Structure

```
privacy/
├── __init__.py          # Public API exports
├── distances.py         # GPU-accelerated (+ CPU fallback) batched k-NN
├── metrics.py           # 6 privacy metrics + PrivacyEvaluator orchestrator
├── visualization.py     # Plotting functions for each metric
├── utils.py             # Data loading, persistence, helpers
└── README.md            # This file
```

### Key files

- **`distances.py`**: Batched k-NN supporting Hamming distance (via one-hot matmul trick on GPU) and Manhattan distance (via cuML or torch.cdist). Auto-detects GPU availability; falls back to sklearn on CPU.
- **`metrics.py`**: Implements all 6 metrics as standalone functions + `PrivacyEvaluator` class that runs them all with **incremental saving** (results saved after each metric to survive crashes).
- **`visualization.py`**: KDE plots (DCR), bar charts (NNAA), ROC curves (MI), histograms (NNDR), scatter plots (MAF), and summary tables.
- **`utils.py`**: `PrivacyDataBundle` dataclass, checkpoint-based and manual data loading, pickle/JSON persistence.

## Quick Usage

```python
from snpgen.evaluation.privacy import (
    PrivacyEvaluator,
    load_privacy_data_from_checkpoint,
    load_privacy_data_manual,
    plot_privacy_summary_table,
)

# Load data from a checkpoint with config.yaml
bundle = load_privacy_data_from_checkpoint(
    ddpm_checkpoint_dir="/path/to/ddpm_checkpoint/",
    model_name="T2D",
)

# Or manually for models without config.yaml
bundle = load_privacy_data_manual(
    dataset_path="/path/to/real_data.hdf5",
    ddpm_checkpoint_dir="/path/to/ddpm_checkpoint/",
    vae_checkpoint_dir="/path/to/vae_checkpoint/",
    model_name="CAD",
    seed=42,
)

# Run evaluation
evaluator = PrivacyEvaluator(distance='hamming', per_class=True)
results = evaluator.evaluate(
    bundle,
    output_dir="/path/to/ddpm_checkpoint/privacy_results",
    eval_target='synthetic',  # or 'reconstructed'
)
```

## Distance Metrics

**Hamming** (default): Counts mismatching SNP positions. Natural for discrete {0,1,2} data.
- GPU implementation uses the one-hot matmul trick for fast batched computation.

**Manhattan (L1)**: Sum of absolute allele count differences. Dosage-aware (0→2 counts as 2, 0→1 counts as 1).
- Uses cuML NearestNeighbors if available, otherwise batched torch.cdist.

Both have CPU fallbacks via sklearn NearestNeighbors.

## Output Format

Results are saved in two formats:
- **`privacy_results.pkl`**: Full pickle with all result dataclasses (including distributions for plotting).
- **`privacy_summary.json`**: Human-readable JSON with scalar metrics only.

Save locations:
- Synthetic privacy → `{ddpm_checkpoint_dir}/privacy_results/`
- Reconstruction privacy → `{vae_checkpoint_dir}/privacy_results/`
